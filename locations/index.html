How it works

The Rules

One code per spot

A location keeps its code across every method, so a left chest logo can move from embroidery to BGX Print without changing anything in the store.

Measured from the collar

Every placement is measured from the bottom of the collar, front or back. Pants measure from the waistband, caps from the visor seam.

Shared default width

The store loads the default width first. If a method's max is narrower, that method uses its max instead (embroidery full front loads at 10").

Max size by method

Each method's max comes from its equipment: hoop, cap frame, screen or printer bed. Method pages list the full rules.
