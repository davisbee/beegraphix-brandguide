# BeeGraphix Brand Guide

Source for brand.shopbgx.com: the BeeGraphix brand guide plus the decoration spec pages
(embroidery, screen print, BGX Print, DTF, DTG, glitter flake, rhinestones, leather patches,
custom patches, hard goods) and the master locations list.

Plain static HTML. No build step. Cloudflare Pages deploys the repo root as-is.

- `index.html` is the brand guide; each spec page lives in its own folder.
- `logos/`, `fonts/` and the two kit zips are the downloadable brand assets.
- `_headers` sets Cloudflare cache and security headers.
- Items marked "Flagged" on a page are open questions listed in that page's "Where It Stands" checklist.
