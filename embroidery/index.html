Won't Reproduce in Thread

These go to art review for a simpler version, or to DTF or a patch instead.

  • Gradients, fades and photographs
  • Halftones, distressed textures and fine drop shadows
  • Thin outlines around small text
  • White text on light garments with no outline

Rules

  • Layouts: one line, two lines, or name plus big number.
  • Name: max 14 characters per line.
  • Number: max 2 digits.
  • Thread color: any of the 31 standard colors.
  • Size: text never goes below its font's minimum height. If a name will not fit a location at that height, the store blocks it rather than shrinking it.

3D Puff Rules

Cap fronts only, as an extra charge.

  • Structured caps only. Unstructured caps collapse the foam.
  • Block or sans serif lettering and bold shapes. No script, outlines or fine detail.
  • Minimum letter height 0.5" and minimum stroke width 0.1".
  • Max size 4.5" W x 2.15" H, same as CF.
  • Puff elements run in one color; flat elements can add other colors.

08 · Status & Sources

Where It Stands

Setup progress for the Brandfora build, and where the numbers come from.

Setup Checklist

  • Confirm exact Mighty Hoop inventory against the hoop column. The spec now uses 4.25", 5.5", 7.25", 13" x 8", 13" x 11" and 15" x 12".
  • Confirm we own the 4.25" x 13" sleeve hoop. If not, hide LSD / RSD.
  • Confirmed: EMT16X runs OS Flex+, Summit runs Summit Manager. Lite blocks the 15" x 12" and sleeve hoops.
  • Ask Melco to confirm Summit supports our Mighty Hoops. Their compatibility list names EMT16 and EMT16Plus but not Summit.
  • Thread brand: Madeira Polyneon. Stock color list added above.
  • Set price tiers against the stitch count ranges, plus the puff upcharge (Davis).
  • 3D puff: yes, cap fronts only, extra charge.
  • Finish personalization rules: fonts set (Athletic Block, Block, Brody, Script, Brush Script); locations, characters and colors set.
  • Map these columns to Brandfora's decoration location fields once we see its admin form.
  • Left hip (HP): keep or remove? Sizes are set; placement is not. Flagged
  • Full back on hoodies: confirm the placement (markup reads 6" down). Flagged
